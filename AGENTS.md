# Project instructions
- No paid APIs, subscriptions, credit purchases, or automatic model downloads.
- Classify through installed local Ollama or use Codex batches within the existing allowance.
- Never print, commit, or transmit authentication headers, cookies, or tokens.
- Keep personal library exports, classifications, and sync state in ignored data/.
- Never remove likes, delete songs, or modify playlists this project did not create.
- Obtain explicit user approval of the current preview before running apply.
- Use small, meaningful commits with truthful messages; never fabricate history.
- Use isolated Python environments and remove disposable environments and
  packages after use.
- Never uninstall pre-existing user packages or delete backups/auth without consent.
- Record progress and remaining work in MEMORY.md without secrets or song metadata.
